# Reference evidence and original synthesis ledger

Optional working template for reference analysis/synthesis. Use the rows needed for the task; a complete franchise inventory is not mandatory. Keep authoring notes outside reader/player-facing prose.

## Intake

| Source ID | Work / creator | Edition, translation or adaptation | Accessible material | Actual coverage | Spoiler ceiling | Priority / wanted effect |
|---|---|---|---|---|---|---|
| ref-a | supplied work | specific version if known | excerpt / full text / episode / panels / summary | exactly what was inspected | user choice or visible assumption | supplied emphasis |

Record versions separately: a novel, manga, anime, manhwa/webtoon or film adaptation can differ in both world facts and technique. Never blend them into one unqualified continuity. User recollection and secondary summaries are accessible evidence of a report, not direct observation of the work.

Infer optional preferences visibly and continue available work. When evidence is absent, state the limitation and request a specific passage only if needed for the requested conclusion. No invented page/chapter/episode/timecode/panel locators or full-work coverage.

## Evidence card

- **Claim ID and source/version:** stable local note.
- **Locator:** exact available page/chapter/episode/timecode/panel, or “locator not supplied.”
- **Evidence type:** direct observation / interpretation / secondary-source report / proposal.
- **Observation:** what the accessible material demonstrates, with a short paraphrase.
- **Desired effect:** what the user wants the audience to experience.
- **Technique:** the mechanism producing the effect; distinguish evidence from inferred intent.
- **Medium dependence:** prose attention, image sequence, animation timing, performance, audio, player agency, shared-state timing, etc.
- **Alternative explanation / disagreement:** attributed source/version or analytic uncertainty.
- **Transfer candidate:** how an original mechanism could work in this project.
- **Cost:** density, pacing, comprehension, production/delivery or state constraints.
- **Coverage/confidence:** confidence in this observation, not a claim about the whole franchise.

Quote a short evidential fragment only when useful and permissible. Prefer paraphrase and locator. Do not output full copyrighted chapters, scripts or transcript dumps. Analysis of a user-supplied excerpt does not authorize signature imitation in original writing.

## Synthesis ledger

| Idea ID | User goal / priority | Evidence technique | Original transformation | Canon fit / affected facts | Medium and persistent-world cost | Status |
|---|---|---|---|---|---|---|
| idea-a | desired effect | evidence-card ID, source version | new causes, actors, relationships and wording | baseline entity/revision or bounded proposal | concrete tradeoff | proposed / selected / rejected / unresolved |

Current user instructions can revise earlier canon through an explicit change record. Otherwise accepted user canon outranks references. Preserve supplied weights; equal-weight combination applies only when requested.

An original transformation changes the causal design, not just names. Do not carry over source proper nouns, distinctive expressions, iconic scenes or a plot sequence wholesale. Do not treat a rank/gate/solitary-hero convention as a default setting fact.

## Compatibility questions

Select only questions relevant to the candidate:

- Does it fit tone and physical costs/limits?
- What material, historical or institutional consequences follow?
- Can the audience understand immediate action despite optional mystery?
- Does the original medium's technique survive the chosen form/length?
- Can multiple players participate without incompatible shared physical facts?
- Are knowledge, attendance, credit, personal progress and shared state distinguished?
- Does it conflict with this project's preference against hard dungeon instances?
- Which important facts remain deliberately unknown?
- Which direct and reverse dependencies would a consequential revision affect?

## Handoff

Return the original candidate and its rationale, evidence limits, compatibility tradeoffs and bounded additions/revisions. The relevant world/narrative discipline formalizes it; canon registration does not imply runtime deployment.
